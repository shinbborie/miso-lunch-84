About this prototype

무엇인가요

미소의 맛집 84선 — 태평로·시청에서 점심 고르는 일을 3초로 줄여 보려고 만든 단일 HTML 웹앱입니다. 서버도, 로그인도, 유료 API 키도 쓰지 않습니다. 파일 하나를 열면 바로 돌아갑니다.

데이터

시청·서소문·북창동·태평로 직장인 맛집 84곳의 식당명과 대표 메뉴를 그대로 담았습니다. 메뉴 설명은 고르기 쉽게 한 줄로 다듬었습니다.

저장

찜한 곳과 최근 뽑기 기록은 localStorage로 이 브라우저에만 저장됩니다. 어디로도 전송되지 않고, 브라우저 데이터를 지우면 함께 사라집니다.

지도는 왜 링크인가요

확인되지 않은 위경도 좌표를 만들어 지도에 찍는 대신, 84곳 전부를 네이버 지도와 카카오맵에서 하나씩 찾아 그 매장의 상세 페이지로 연결했습니다. 그래서 지도 버튼을 누르면 검색 결과 목록이 아니라 매장 화면이 바로 열립니다.

지도에서 끝내 확인되지 않은 곳은 정메모 한 곳입니다. 그 카드에는 버튼 대신 지도 미확인 표시가 있습니다.

만든 방식

AI와 대화하며 만들었습니다(바이브 코딩). HTML·CSS·JavaScript 세 덩어리, 외부 라이브러리 없음. 통째로 복사해 다른 목록으로 바꿔도 그대로 동작합니다.

※ 메뉴와 영업 정보는 시간이 지나면 달라질 수 있습니다. 방문 전에 지도 앱에서 영업 여부를 한 번 확인해 주세요.

홈 화면에 추가

두 번만 누르면 홈 화면에 아이콘이 생겨요.

    한 번 추가하면 다음부터는 아이콘만 눌러 주소창 없이 열립니다. 홈 화면에서 언제든 지울 수 있어요.
